# Task Management System

A role-based Task Management System developed using PHP, MySQL, REST APIs and JWT authentication.

## Features

- User authentication
- JWT-based authentication
- Role-based access control
- User management
- Role and permission management
- Task creation and assignment
- Task tracking and updating
- Task priorities and due dates
- RESTful APIs
- MySQL database integration
- Admin and user workflows

## Tech Stack

- PHP
- MySQL
- REST APIs
- JWT
- HTML
- CSS
- XAMPP

## Project Structure

The application follows a structured backend architecture using controllers, routes and middleware.

## Setup

1. Install XAMPP.
2. Place the project inside the `htdocs` directory.
3. Create the required MySQL database.
4. Configure local database credentials in `.env`.
5. Start Apache and MySQL from XAMPP.
6. Run the application locally.

## Note

Environment variables and local database credentials are excluded from this repository for security reasons.
